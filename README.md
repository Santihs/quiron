# quiron

A knowledge model layered on top of Obsidian vaults used with Anki. Anki
schedules cards; quiron models concepts, evidence, doubts, and coverage. See
`Quiron.md` (plan v7) for the full design, and `DECISIONS.md` for the
decisions made while implementing each phase.

## Usage

```
uv sync
uv run quiron seed --vault ../karpathy-path          # seed/refresh knowledge.json
uv run quiron capture-scan --vault ../karpathy-path   # new callouts -> inbox.jsonl
uv run quiron today --vault ../karpathy-path          # the only command you need to remember
uv run quiron cards --vault ../karpathy-path --decide      # retention decision walker
uv run quiron cards --vault ../karpathy-path --list-gaps   # needed-but-empty concepts
uv run quiron doctor --vault ../karpathy-path --json  # findings: dangling refs, orphans, loose doubts
```

`seed` and `capture-scan` are idempotent — running them again never
duplicates or overwrites what you already generated by hand (`evidence`,
`doubts`, `card_policy`).

## Status

**Fase 1** — capture via callouts, seeding from `02-Topics/` +
`04-Quiz-Bank/karpathy/` + `06-Doubts-Resolved/`, and `quiron today`. Never
touches `progress.json`.

**Fase 2** — `card_policy` decisions become real (`quiron cards --decide`),
coverage gaps are computed from that decision, and AnkiConnect is wired for
the one v7 question that needs it without overlapping Fase 3: the
understand-vs-recall contradiction. `quiron today` never fails when Anki is
closed — it just omits that line.

Not yet built: card-quality audit (Fase 3), full evidence wiring through
`quiz-me` (Fase 4), a second vault (Fase 5), a parametrized reviewer (Fase
6), a copier template (Fase 7).
